## Common issues

**Overlay intercepts clicks:** press Ctrl+M on Windows to toggle click-through, or Ctrl+\ to hide the overlay. Consult Help & Contact if shortcuts were rebound.

**No audio or screen context:** check the selected capture mode and operating-system permissions, then check the chosen audio device. Platform support differs.

**Access expired or rejected:** check that the token was copied correctly. Contact support for access questions; never post the token in a public issue.

**Paid but waiting for a key:** return to Access on the website, sign in with the same Google account, and use Already paid? for the purchased plan. Recovery checks run while the page is open; reopening restores the pending reminder. Contact support if delivery remains unresolved.

**Privacy or deletion question:** see [PRIVACY.md](PRIVACY.md). Exported files and provider-held records are separate from local desktop data.

Security issues should be reported privately using [SECURITY.md](SECURITY.md).
