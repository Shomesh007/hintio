# Security reporting

Report suspected vulnerabilities privately to **admin@builtbygsv.in**. Include the affected version or commit, a minimal reproduction, impact, and redacted diagnostic information.

Do not publish working credentials, access keys, personal data, or exploit details in public issues. Use test accounts and synthetic content when demonstrating an issue. Do not access another person's records or disrupt a live service.

The latest maintained source is on `main` for the website and `desktop` for the Electron application. Older tags are historical snapshots. No guaranteed response window or bounty program is stated here.

Desktop credentials and history are currently stored in local JSON files; see [PRIVACY.md](PRIVACY.md). Never commit `.env` files, private resumes, session history, signing certificates, provider keys, or backend service-role credentials.
